# Latin Montserrat faces

Generated by `tools/gen_latin_fonts.sh` (issue #99). Do not edit the `.c` files by hand.

These replace LVGL 9.5's built-in `lv_font_montserrat_<N>` under the same names, adding
Latin-1 Supplement, Latin Extended-A and the euro sign to the built-ins' ASCII, degree
and bullet, so accented letters (á é í ó ú ñ ü ¿ ¡ and friends) draw instead of showing
a missing-glyph box. The icon symbols are LVGL's own set, unchanged, and each face keeps
LVGL's line height and baseline so no layout moves. `src/lv_conf.h` switches LVGL's
copies off and declares these.
