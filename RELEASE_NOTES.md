### New
- Nodes list: a new **All** button above Search shows every node at once, including archived nodes when **Show Archived Nodes** is on. The header reads `All nodes (n)`, and Clear search returns to favorites.
- Node search accepts wildcards: `*` matches any run of characters and `?` matches any single character, including an emoji. A search with a wildcard must match the whole name or ID. For example, `mi*` finds names starting with "mi", `*base` finds names ending in "base", and `!1a2b*` finds IDs starting with `1a2b`. A search without a wildcard still matches anywhere in the name.

### Changed
- On keyboard devices, pressing Up from the top of the Nodes list moves to Search, then to All. Down moves back.
- The "Chat Server" option has been removed from the node actions menu.
