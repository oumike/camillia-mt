### New
- Config now has a **Screen Timeout** row next to Brightness, with a slider for 15 sec, 30 sec, 1 min, 2 min, 5 min, 10 min or Never — the display sleeps after that much idle time.
- T-Deck and Attaky Mesh Deck: the bottom of the screen is now a row of tappable buttons — Home, Config, DM, Nodes, Live and Help — replacing the key-hint text. The keyboard shortcuts still work, and each button prints its key beside the icon.
- New **Nav Bar** setting on the T-Deck and Mesh Deck (Config screen and the web config page) turns that button row off and brings the old keyboard shortcut hints back; the screen redraws immediately, no reboot needed.
- A **Home** button on the far left of the nav bar closes whatever screens are stacked up and returns straight to chat.
- Heltec V4 and Square: the node action menu now has a corner **X** to close it, so you no longer have to pick an action to get out of it.

### Changed
- Nav bar buttons are now icons instead of words on Heltec V4 and Square, and the buttons read the same size on both the wide and tall layouts.
- Heltec V4 and Square: the nav bar now runs edge to edge along the very bottom on every screen, so the buttons no longer shift position as you move between chat, Config, DM, Nodes and Live.
- T-Deck and Mesh Deck: the GPS, WiFi and unread-DM icons now stay visible on the Config, DM, Nodes and Live screens instead of disappearing until you return to chat.
- The chat screen's button row is slightly shorter, giving a few more pixels to the message list.
