### New
- **T-Display P4:** In landscape, the nav bar is now a narrow column down one side of the screen. Each button shows its icon with its F-key underneath, so every screen gets its full height back.
- **T-Display P4:** You can now choose which side the landscape nav column sits on. The default is left. Change it under Settings → Nav Bar Side or in the web config's Display section. The change applies immediately, with no reboot.

### Changed
- **T-Display P4:** In landscape, the channel list now slides in as a drawer instead of taking up a fixed column beside the chat, which leaves the chat more room.
- **T-Display P4:** The Keyboard Light row in Settings only appears when the keyboard is attached. Instead of opening a level picker, it now tells you to press F11 to change keyboard brightness.
- The divider line on the lock screen and home dashboard now runs the full width of the screen.

### Fixed
- **T-Display P4:** The Keyboard Light setting no longer shows a brightness level that didn't match what the keyboard was actually doing.
