### New
- A thin vertical rule now runs down the middle of the lock screen and home dashboard header, separating the node name and clock from the sky and temperature beside them.

### Changed
- When there is no weather reading to show — none ever fetched, no weather server set, or the cached one too stale to trust — the node name and clock now centre on the panel instead of sitting against the left edge with empty space next to them, and the divider hides. Both shift back to the left column as soon as a reading arrives.
