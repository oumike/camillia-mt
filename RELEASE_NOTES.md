### Changed
- The L key and the on-screen navigation bar now open Tools instead of the Live feed; Live is the first entry in the Tools list, one tap further in.
- Tools can be opened from anywhere — the chat screen, the nav bar, or the L key — instead of only from inside the Live feed.
- Tools gained a Live row (shortcut L), so the feed and the SNR/RSSI and channel-utilization charts all start from the same list.
- Backing out of a chart now returns to wherever Tools was opened from: the Live feed if you came from there, otherwise the chat screen.
- The Live feed's header no longer has a Tools button, since Tools is now the screen you arrive from.
- Elecrow ThinkNode M9: the function button below Home now opens the node list, and the button in the GPS area below Back opens Tools.
- T-Lora Pager and T-Deck/Mesh Deck/Cardputer: Alt+L now opens Tools.
- On-screen key hints and the shortcut legend now read "Tools" in place of "Live".

### Fixed
- T-Deck Pro: the direct-message button on the navigation bar showed as a solid filled block on the black-and-white panel; it now uses a speech-balloon icon that renders correctly at every size.
